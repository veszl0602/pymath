문제 찾기 도구 찾기 함수 사전 안내서 소개

처음 쓴다면 이것만

  1. from sympy import * 를 맨 위에 쓴다.
  2. x = symbols('x') 로 문자를 먼저 만든다.
  3. 분수는 Rational(1, 2). 그냥 1/2는 0.5(소수)가 된다.
  4. 대문자 Sum · Limit · Integral은 식을 적어 두고 .doit()으로 계산한다. 소문자는 바로 계산한다.
  5. 방정식은 Eq(좌변, 우변). =는 쓸 수 없다.

SymPy는 √2, π를 기호 그대로 계산하는 라이브러리, NumPy·SciPy는 소수로 빠르게 계산하는 라이브러리다. 구글 코랩에 모두 설치되어 있다.
